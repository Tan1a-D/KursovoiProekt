# Wallpaper Desktop

Приложение для автоматической смены обоев рабочего стола.

## Возможности
- добавление фотографий;
- автоматическая смена обоев;
- ручная смена;
- выбор интервала;
- автозапуск.

## Запуск программы
Запустить файл `WallpaperDesktop.exe`.

Для запуска Python-версии:

```bash
python3 main.py
```

## Требования
- Windows 10/11

## Используемые технологии
- Python
- Tkinter
- SQLite
- WinAPI

## Поддерживаемые форматы

`JPG`, `JPEG`, `PNG`, `BMP`, `GIF`, `WEBP`.
